# TC-08: Combined + Split Mix (Grey Box)
**Category**: Section & Split Constraints

- **Objective**: Can a COMBINED course coexist with SPLIT courses in the same semester?
- **Setup**: MA163 (COMBINED, all students) + CS163 A/B (SPLIT). Same semester.
- **Expected**: PASS

### Results
- **Unscheduled**: 0 (Pass)
- **Insight**: The scheduler correctly routes COMBINED courses to all section timetables and SPLIT courses to only their designated section.
